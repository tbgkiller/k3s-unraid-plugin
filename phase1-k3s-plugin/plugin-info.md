# k3s Plugin

Lightweight Kubernetes (k3s) for Unraid

## About

This plugin installs k3s v1.35.2+k3s1, a lightweight Kubernetes distribution perfect for running containerized workloads on Unraid.

## Usage

After installation, start k3s with:
```
/boot/config/plugins/k3s-plugin/start.sh
```

Stop with:
```
/boot/config/plugins/k3s-plugin/stop.sh
```

## Configuration

k3s config: `/etc/rancher/k3s/config.yaml`
